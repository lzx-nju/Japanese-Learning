# 日语自学练习（起始版）

一个**本地跑的单人日语练习 Web 应用**：词库按课程组织，15 种单项题型 + 多邻国式混合课
（先学后练、错题回炉）+ 助词填空 + JLPT N5 真题 + 作品阅读器 + 图片日语。
没有账号体系，数据就是本地几个 JSON/CSV 文件。

## 三条命令跑起来（Windows）

1. 装 Python 3（开发与测试用的是 3.13，3.10+ 应该都可以）
2. `python -m pip install -r requirements.txt`——清单里只有 `flask` 是启动必需，
   其余缺了只影响对应功能（注释里写明了「装它是为了什么、缺了会怎样」）
3. 双击 `start_practice.bat`（解释器会自动探测；或手动 `python practice\app.py`），
   浏览器打开 http://127.0.0.1:5000

首次启动会从 `data/seed/vocabulary_seed.json` 自动生成 `vocabulary.json`
（N5 官方词表 + 几门示例课程，掌握度全 0）。练习记录写在 `quizzes/`——
这两个东西都已经在 `.gitignore` 里，不会污染仓库。

## 开箱能玩什么 / 会缺什么

| 功能 | 起始状态 |
|---|---|
| 词库 15 种题型、课程模式、学新词、助词填空、汉字卡、动词活用卡、统计与错题本 | **完整可用** |
| 单词发音 | 首次碰到听力题时联网用 `edge-tts` 现生成（没装就没声） |
| 「看图选汉字 / 看图选发音」 | 仓库不含配图，这两个题型**自动不出题**（不会报错，补图即生效） |
| 真题实战 | **完整可用**：188 题，含官方聴解音频与插图（`practice/static/exam/`，40MB）。不想要这部分可整目录删掉——删了聴解题就放不出声，用练习页的「🔇 跳过听力题」开关可以整批跳过 |
| 作品沉浸 | 只有自写的示例 `data/works/demo_n5/`；导入自己的 txt/epub/音声即可用 |
| 图片日语 | 带一课示例（驱蚊喷雾）。换成自己的照片、照着 `lessons/图片日语_示例课.md` 写一份，跑一次导入器就是新课 |
